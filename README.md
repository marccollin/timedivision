# TimeDivision ⏱️

**TimeDivision** est un outil web simple, autonome et léger permettant d'effectuer des opérations de division et de répartition temporelle de garde d'enfant. Conçu entièrement dans un fichier HTML unique (`timedivision.html`), cet outil ne nécessite aucune installation ni aucun serveur backend pour fonctionner.

---

## Fonctionnalités Principales

- **Jour de départ de l'enfant** : Mentionné le jour de départ de l'enfant
- **Type de garde** : 7/7, 5/2/2/5 ou 3/2/2/3
- **Heure de bascule** : Heure de départ de l'enfant
- **Interface légère et réactive** : Fonctionne directement dans le navigateur client sans aucune dépendance lourde.
- **Utilisation hors-ligne** : Peut être exécuté en local sans connexion Internet.

## Prise en main rapide

### 1. Utilisation directe

Vous pouvez utiliser le fichier directement depuis votre navigateur :

1. Téléchargez ou clonez le dépôt :
   ```bash
   git clone https://github.com/marccollin/timedivision.git
   ```
2. Ouvrez le fichier `timedivision.html` dans n'importe quel navigateur moderne (Chrome, Firefox, Edge, Safari, etc.).

### 2. Déploiement avec GitHub Pages

Si vous souhaitez rendre l'application accessible en ligne gratuitement :
1. Allez dans les **Settings** de votre dépôt GitHub.
2. Accédez à la section **Pages**.
3. Choisissez la branche `main` et le dossier racine `/ (root)`.
4. Enregistrez : l'application sera accessible en ligne à l'adresse `https://marccollin.github.io/timedivision/timedivision.html`.
